## 1. 一句话定位

住在你电脑里的 AI 恋人管家：他看得见你的任务、习惯、作息与重要日，会主动留言、关心与提醒——而不是等你打开聊天框他才出现。

- 关键词：人机恋 × 日程管理 × 陪伴式成长
- 代号：MyHaruto

## 2. 核心目标与边界

| 项 | 决策 |
|---|---|
| 本期范围 | Windows 桌面单机版（MVP），数据全本地 |
| 用户 | 开发者本人 1 人，不做多用户 |
| 发布路径 | 自用 → 开源 GitHub → 有人用再考虑开放与多端 |
| 本期不做 | 云同步、账号系统、移动端、2D 小镇（仅留入口）、Live2D 全身动画、看板视图与任务拖拽（→ V2/V3） |

## 4. 功能需求

### P0 — MVP

**F1 任务**
- 标签式分类，每标签可设颜色（侧边栏圆点/月历色块/统计图一处定义处处生效）
- 特殊标签「年度OKR / 我的愿景」固定排在普通标签上方，结构与普通标签一致
- 「今日任务」顶置独立页：今天到期 + 手动加入的任务汇总，位于所有标签之前
- 子任务：默认只见主任务框，单击主任务展开子任务；主任务框内标题下方显示进度条（3 个子任务完成 2 个 = 66%）
- 任务关联：独立任务可关联到主任务，专注时长并入主任务统计
- 描述：主/子任务均可写；双击任务框编辑标题与描述
- 番茄钟：任务条目带 🍅 入口直接开始；计时页 = 左大圆环（中心 HH:MM）+ 开始/暂停/放弃，右侧今日概览+历史专注记录；顶部「番茄计时 / 正计时」切换；时长自定义；每段计时必须归属具体任务

**F2 月历**
- 7 列（日~六）× 6 行网格，日期数字左上角
- 任务以彩色色块+白色文字显示，多条垂直堆叠；色块颜色 = 标签颜色
- 今天：蓝色圆形背景高亮；工具栏：`+` 新建 / `月` 视图切换 / `< >` 切月 / `今天` 回位 / `···`
- 与任务实时联动；点击日期查看与新增任务

**F3 习惯打卡**
- 周视图：顶部星期时间轴（今天高亮），每行一个习惯（彩色图标+名称+连续天数⚡+最长纪录🔥），打卡格深灰圆→打卡后变绿+白对勾（弹跳动效）
- 月视图：竖排 1-31 天；顶部竖排习惯名+两个竖排数字（橙红=月目标可编辑、茶绿=当月已打卡）；数据与周视图同步
- 年视图：透明边框表格，习惯名列 +「已打卡 / 目标打卡」汇总

**F4 数据统计**
- 番茄饼图（日=子任务粒度；月/年=仅主任务，子任务与关联任务时长自动并入）
- 月热力图：GitHub 式格子，越深当天越专注
- 月入睡折线图：横轴日期，纵轴入睡时间 21:00→05:00 连续；每天 09:00 AI 问"昨晚几点睡的"，口语解析（"1点半"→01:30）；凌晨 0-5 点入睡归属前一天；进新月物理删除上月
- 铁律：任务关联/迁移时历史专注时长跟着迁移

**F5 重要日**
- 多重要日（生日/节日/自定义），可重复、提前 N 天提醒（默认 7）
- 生理期：迷你月历点选开始/结束，浅红覆盖预测日（平均周期推算），可修正
- 提醒 = AI 自然聊天式提起（生日等提前 7 天、生理期预测前 3 天）；重要日为硬记忆

**F6 AI 聊天（灵魂模块）**
- 仿微信：双方每条消息带头像（他左你右），可换头像/聊天背景，拍一拍（双击头像抖动+回应）
- 页面：左 1/3 立绘（表情切换），右 2/3 气泡对话+输入框（📎 发图）
- 图片走视觉识别（双模型路由：带图→视觉模型，纯文字→文本模型）
- 人设 = persona.md 独立配置文件

**F7 人物主页**（点聊天页顶部头像进入）
- 头像+名字 → 人物设定卡 → 当前情绪 → 悄悄话（今日日记预览两行，点击进历史，一天一篇）

**F8 AI 定时行为**
- 权限：所有数据只读；唯一写权限 = 任务描述区追加留言（海蓝斜体双引号），永不删改
- 行为清单见 §6

### P1 — V2
书影清单（按月相册流，跨年折叠）、旅游札记（按地点）、看板+拖拽、记忆系统 v1（三层记忆+活跃分衰减：频率×新近度×情绪权重，高情绪价值衰减慢）

### P2 — V3
2D 小镇、Live2D、移动端、云同步

## 6. AI Agent 行为规格

### 6.1 权限模型
| 数据 | 读 | 写 | 删/改 |
|---|---|---|---|
| 任务/习惯/统计/重要日/相册 | ✅ | ❌ | ❌ |
| 任务描述区 | ✅ | 仅追加留言 | ❌ |
| 聊天记录 | ✅ | ✅（仅聊天内） | ❌ |

### 6.2 定时行为清单
| 行为 | 时间 | 动作 |
|---|---|---|
| 读今日任务并留言 | 每天 2 次，时间可配 | 挑 2-3 条留言（海蓝斜体双引号） |
| 入睡问询 | 每天 09:00 | 问"昨晚几点睡的"，解析入库 |
| 悄悄话日记 | 每天 23:30 | 写当日小日记；未开机则启动时补写 |
| 重要日提醒 | 生日等提前 7 天；生理期预测前 3 天 | 自然聊起 |
| 月度阅读 | 每月 1 次 | 浅读番茄统计+习惯打卡 |
| 年终总结 | 每年 12 月末 | OKR 完成率、任务投向、习惯表现 |

## 7. 用户地图（每日循环）

```
09:00 他主动问入睡时间（红点+气泡+轻提示音）→ 回复入库 → 折线图更新
白天   加任务 → 详情 → 🍅专注（自定义时长）
       第1次读取时间 → 他看今日任务 → 挑2-3条留言
晚上   习惯打卡 → 聊天/发图（视觉识别）→ 第2次读取 → 晚安留言
23:30  他写悄悄话日记（人物主页可看）
```
周期：重要日前 7 天/生理期前 3 天自然提起 → 每月 1 日月度阅读 → 12 月年终总结
首次使用：打开 → 建第一个标签 → 建第一个任务 → 和 Haruto 说第一句话

## 8. 视觉规范

- 日间：暖白底、深灰字、海蓝强调（飞书感）
- 夜间：主底 #1E1E1E、侧边栏 #121212、浅字、彩色圆点保留
- 跟随系统自动 + 手动切换，记住选择
- 标签色系一处定义处处生效
- 微动效：打卡弹跳变绿、AI留言淡入、番茄钟圆环、气泡滑入、拍一拍抖动、主题渐变

## 9. 技术架构（已确认）

```
界面层  React + TypeScript + Tailwind
应用层  Electron（桌面壳+后台常驻+定时器）
数据层  SQLite + 本地图片文件夹
AI 层   DeepSeek/GLM(文本) + GLM-4V(视觉)，双模型路由；persona.md 人设解耦
```

| 选型 | 理由 |
|---|---|
| Electron | AI 生成代码最稳；托盘常驻+开机自启是定时行为前提 |
| React+TS+Tailwind | AI 最熟练；极简+微动效效率最高 |
| ECharts | 饼图/热力图/折线全覆盖 |
| SQLite | 单文件零配置 |
| 双模型路由 | 带图走视觉，纯文字走文本，成本最低 |

工具分工：zcode(GLM)=开发主力；DeepSeek harness=代码审查/攻坚；GitHub Desktop=版本管理。
成本：月个位数到低位数元。
