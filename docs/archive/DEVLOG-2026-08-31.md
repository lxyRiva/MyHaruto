## 三、关键技术决策与教训

### 根因级修复

1. **时区 bug**（影响月历/番茄池/统计三个表象）：`toISOString().slice(0,10)` 取的是 UTC 日期，北京时间 0-8 点比本地早一天。所有本地日期比对统一改为手工拼装本地日期。教训：**日期只存 `YYYY-MM-DD` 字符串，显示/比对全走本地时区**。
2. **Bug2 · L2 点击失效**（两次）：
   - 第一次：修正3 给 L2 行加 `draggable` 实现拖拽排序——HTML5 规定 mousedown 后移动 1-2px 即启动拖拽并**吞掉 click**，触摸板点击几乎必然触发。修复：拖拽把手模式（行首 ⠿ 把手才 draggable，行点击不受影响）。
   - 第二次（残余）：`selectSubTag` 不重置 `activeListId`——最近7天页点 H2 后 activeListId 残留 `'recent7'`，L3 路由 recent7 分支优先于 activeSubTagId 分支，永远渲染 Recent7View。修复：selectSubTag 同步 setActiveListId(所属H1)。
   - **教训：路由分支依赖互斥全局状态（activeListId/activeSubTagId/page）时，切视图入口必须成套同步设置；`draggable` 与 `onClick` 不能共存于同一元素。**
3. **FloatingMenu 二级菜单弹不出**：父容器 `overflow-y-auto` 使 overflow-x 强制非 visible，`absolute left-full` 的子菜单被横向裁剪。修复：子菜单改 `fixed` 定位（无 transform 祖先时不受 overflow 裁剪）+ hover 延迟关闭。

### 架构决策

- **单一数据源**：所有视图（今日/最近7天/全部/看板）只吃 App.tsx 下发的 db.tasks 与同一组 setDb handler，无本地副本——任何视图修改全视图同帧同步。
- **菜单单一来源**：`buildTaskContextMenu` 是四视图唯一右键菜单构建器，支持可选 `masterLink`（旧列表页真实关联）等扩展参数。
- **可选字段代替自愈**：Task.aggregated/remindAt/remindDaysBefore、Tag.isPinned 等后加字段全用可选（undefined 当默认值），避免频繁动 main.js 自愈。
- **聚合语义**（需求方定稿）：勾选完成只原位灰显；点「聚合」才把 done 任务（aggregated 标记）移入折叠区；取消完成清标记。
- **土办法哲学**：无路由库（useState 切页）、无状态库（App 单点 state）、单 JSON 文件存储——对单人项目 + AI 改码是最优取舍。

### 流程经验

- 需求卡（极详细规格、验收标准、禁止事项）→ 实现 → 需求方验收 → 授权提交：全程零返工争议。
- AI 验收方式：tsc 零错误 → build → 必要时 UI 自动化实测（Electron a11y 树不稳定，帧绑定常失效，重试策略见记忆）；用户在用电脑时不抢焦点，交付报告让用户自行点验。
- 多文件 props 穿线易漏解构/透传——tsc 报错集中修即可。
