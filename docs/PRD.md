# MyHaruto 产品需求文档（PRD）

> 版本 v1.2 ｜ 更新 2026-08-24 ｜ 本文件是产品功能的唯一权威描述，与实际实现同步维护。
> 开发任何功能前先读本文对应模块；改完功能后回来更新本文。

## 1. 产品定位

住在你电脑里的 AI 恋人管家：他看得见你的任务、习惯、作息与重要日，会主动留言、关心与提醒——而不是等你打开聊天框他才出现。

- 关键词：人机恋 × 日程管理 × 陪伴式成长
- 用户：开发者本人（单人使用，无多用户）
- 形态：Windows 桌面应用（Electron），数据全本地
- 路线：自用 → 开源 GitHub（私有仓库 WillaLin-ux/MyHaruto）→ M5/M6 引入 AI 灵魂

## 2. 全局布局（三层结构）

```
┌────┬────────┬──────────────────────┬───────────┐
│ L1 │ L2     │ L3 内容区             │ 右栏详情   │
│图标 │ 清单树 │ （各模块页面）         │ 320px     │
│56px│ 208px  │                      │ 仅任务模块 │
└────┴────────┴──────────────────────┴───────────┘
```
- **L1**：细线 SVG 图标（lucide 风格 1.5px stroke，禁用 emoji）：任务/专注/月历/习惯/统计/重要日/书影(V2)/旅行(V2)/Haruto(M5)/小镇(V3) + 底部日/夜主题切换
- **L2**（仅任务+今天页）：清单树——顶部「今天」入口（☀ 图标+计数）、全部、我的愿景（特殊标签组）、普通清单（彩色圆点+计数）、＋新建清单（名称+6色选一）
- **L3**：模块页面；任务模块选中任务时右栏显示详情

**交互铁律**：任务条目**左键=打开右栏详情，右键=功能区菜单**（任何层级一致）；右键菜单支持二级子菜单（hover 右侧展开+›箭头）。

## 3. 模块功能规格

### 3.1 任务（核心，当前最重）
- **无限嵌套任务树**：主任务（左侧三角▶单击展开/收起）→ 子任务缩进显示（缩进22px/层，行高更紧凑、字号略小）→ 子任务可再有子任务，无层数限制
- 子任务与主任务功能完全一致：勾选/双击改标题/🍅独立计时/完整右键/置顶/关联
- **右键菜单**（分组+嵌套）：
  - 设置日期▸：今天/明天/后天/下周三/下周五/选择日期…（行内 date 选择器）/清除日期
  - 设置优先级：高🔴/中🟡/低🔵/无（行内色点显示）
  - ＋添加子任务（行内输入框，回车创建，自动展开）
  - 关联主任务（排除自身与子孙防环；时长并入其统计；行内显示「↗已关联」）
  - 置顶今日（isPinnedToday）
  - 🍅开始专注
  - 移动到…（标签清单列表）
  - 删除（连带子任务）
- 子任务进度条：主任务行标题下方，颜色=标签色，显示 done/total
- 清单树筛选：全部/今天/标签；分组显示（今天/即将到来/更早/无日期/已完成）

### 3.2 专注（番茄钟）
- 独立页面：任务胶囊在圆环上方（点击弹任务选择列表，**任务池含子任务**）；圆环中心 MM:SS，细环7px海蓝进度
- 按钮：放弃 | 开始/暂停（大高亮）| 完成 | 重开
- 顶部「番茄计时/正计时」切换：**正计时无时间限制**（隐藏分钟选择）；倒计时 15/25/45/60+自定义
- 右侧统计面板：今日🍅数、今日总分钟、今日专注记录（任务名+分钟+开始时刻）
- 底部浮动计时条（PomodoroBar）常驻：任意页面可暂停/继续/完成/放弃
- **计时归属铁律**：子任务时长沿 parentTaskId 链并入主任务；任务关联主任务（masterTaskId）后其子树时长一并并入——迁移任务时历史时长跟着走

### 3.3 月历
- 周/月视图切换：**周视图**=左侧时间刻度（7:00~23:00 虚线参考）+7列（周一~周日，今天海蓝高亮）+列内任务色块条目，总览用不可编辑；**月视图**=7列×6行格子，任务色块+白字垂直堆叠（颜色=标签色），今天蓝色圆底
- 显示全部任务（含子任务，带「└」前缀）；无日期任务不显示（底栏提示+顶栏计数徽章）
- 点击日期：当日任务速览+勾选+「+添加当天任务」输入框
- 工具栏：‹›切月/切周、今天、无日期计数

### 3.4 习惯打卡
- 周/月/年三视图
- **周视图**：顶部星期一~日（今天海蓝+下划线）；每行习惯（icon+名称+🔥连续天数）；打卡格 w-8 h-8 圆形：未打=空心（灰描边）、已打=实心绿#5b8c5a+白✓；hover:scale-110
- **月视图**：表格制——最左列竖排1~31（今天海蓝）；顶部每习惯一列：icon+横排名（可换行，列宽统一56~80px）+横排两数字：目标N（橙红#e07a5f，点击行内编辑）/打卡N（茶绿#6a994e）；交叉处打卡格 w-7 h-7 rounded-md
- **年视图**：透明边框表格：习惯名 | 已打卡 | 年目标（默认=月目标×从创建月到12月的月数，可点击行内编辑覆盖值，localStorage 存储）
- 习惯右键菜单：编辑名称/更换图标（9个emoji+自定义）/设置月目标/删除

### 3.5 数据统计
- 顶部日/月/年切换（海蓝）
- **饼图**：任务专注占比，莫奈/梵高名家色板（10色循环），日=含子任务明细、月/年=归并主任务
- **年度热力图**（竖排连续填充日历式）：每列14格从上到下连续排日期（第1列=1月1~14日，第2列从1月15日接续，全年约27列）；横轴每3个月标记（1月/4月/7月/10月）；**无纵轴无周几**；颜色5级固定阈值：0/1~30分/31~60分/61~120分/120+分（海蓝渐变，1分钟绝不能深色）；全年满格（未来=最浅色）；hover tooltip「X月X日 · 专注N分钟」；图例标注阈值
- **入睡折线图**（仅月视图）：x=日期，y=入睡时间21:00→05:00连续；connectNulls=false 断点跳过（M6 由 AI 问询自动录入）

### 3.6 重要日
- 卡片：**图上字下**竖版（图60%）——9张 PNG 插画（birthday: 热气球/蛋糕/猫咪；festival: 灯笼/烟花/圣诞；custom: 月亮/纸飞机/绿植，路径 assets/days/）；文字区：标题粗体+日期+倒计时胶囊徽章（还有N天海蓝/就是今天玫红/已过灰）
- **右键菜单**（嵌套）：编辑（原地表单回填）/ 重复▸（不重复·每年·每月·每周·每天）/ 日期▸（公历·农历）/ 置顶（📌排最前）/ 删除
- **农历**：solarlunar 换算显示「农历X月X日」，小字「按公历日期提醒」；编辑表单历法切换+实时农历预览
- 已归档折叠区（可恢复/删除）
- **生理期**（右栏迷你月历）：点干净日期→**居中确认弹窗**「月经开始了吗？[开始][取消]」；已有未结束记录时点其后日期→「月经结束了吗？[结束][取消]」；**绝不自动测算结束**；已记录=浅红#f4a6a6、进行中=深红#e88888（仅开始日单格，不蔓延）、预测=极浅红虚线（平均周期推算，非医疗建议）
