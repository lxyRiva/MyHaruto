# MyHaruto 产品需求文档（PRD）

## 1. 产品定位

住在你电脑里的 AI 恋人管家：他看得见你的任务、习惯、作息与重要日，会主动留言、关心与提醒——而不是等你打开聊天框他才出现。

- **关键词**：人机恋 × 日程管理 × 陪伴式成长
- **用户**：开发者本人（单人使用，无多用户）
- **形态**：Windows 桌面应用（Electron），数据全本地
- **路线**：
  - **v1.0.0 内部版**（MVP）：开发完成，自用观察 + 找 bug + 迭代
  - **v2.0.0 开源版**：含完整小镇/3D/AI 功能，GitHub 私有仓库 WillaLin-ux/MyHaruto

## 2. 全局布局（三层结构）

```
┌────┬────────┬──────────────────────┬───────────┐
│ L1 │ L2     │ L3 内容区             │ 右栏详情   │
│图标 │ 清单树 │ （各模块页面）         │ 320px     │
│56px│ 208px  │                      │ 仅任务模块 │
└────┴────────┴──────────────────────┴───────────┘
```

- **L1**：细线 SVG 图标（lucide 风格 1.5px stroke，禁用 emoji）：任务/专注/月历/习惯/统计/重要日/书影/旅行/Haruto/小镇 + 底部日/夜主题切换
- **L2**（仅任务+今天页）：清单树——顶部「今天」入口（☀ 图标+计数）、全部、我的愿景（特殊标签组）、普通清单（彩色圆点+计数）、＋新建清单（名称+6 色选一）
- **L3**：模块页面；任务模块选中任务时右栏显示详情

**交互铁律**：任务条目**左键=打开右栏详情，右键=功能区菜单**（任何层级一致）；右键菜单支持二级子菜单（hover 右侧展开+›箭头）。

## 3. 模块功能规格

### 3.1 任务（核心）

**视图定位**：
- **横板视图**（今天/最近 7 天/全部）= 时间维度：按日期分组——已逾期/今天/未来日期；用户视角：「我今天要做什么」
- **看板视图**（H1/H2）= 项目进展维度：按 Section 分组，每个分组是一个项目/阶段；用户视角：「每个项目的推进情况」
- 两者**共享同一套任务数据，只是展现维度不同**；排序共用 taskSort 单一实现（铁律 DEV_RULES §10）

**排序规则**（M2-V14 实施；现行 taskSort 仍为日期优先）：
- 权重链：置顶 > 优先级 > **有效日期**（升序）> done 沉底
- 有效日期 = dueDate 优先；无 dueDate 用创建日
- 已完成任务不改变有效日期位置（时间线保真）

**置顶双轨**（最终语义，十八 D 备案）：
- **isPinnedGroup（置顶该组）**：写父任务标记（子任务右键入口保留，写库 target=parentTaskId）；看板读→父组浮同层首；横板不读；取消=父标记清空整组回落
- **isPinnedToday（置顶今天）**：双入口（子任务=改子任务日期为今天；父任务=改自身日期）；横板读→组在今天区块浮顶；子任务取消→日期回设父任务日期；父任务取消→仅清标记日期不回写；手动改日期→自动清 isPinnedToday（updateTask 守卫）；过今天标记保留不生效
- 多浮首组间按 taskSort 相对序

**无限嵌套任务树**：主任务（左侧三角▶单击展开/收起）→ 子任务缩进显示（缩进 22px/层，行高更紧凑、字号略小）→ 子任务可再有子任务，无层数限制

**子任务与主任务功能完全一致**：勾选/双击改标题/🍅独立计时/完整右键/置顶/关联

**右键菜单（分组+嵌套）**：
- 设置日期▸：今天/明天/后天/下周三/下周五/选择日期…（行内 date 选择器）/清除日期
- 设置优先级：高🔴/中🟡/低🔵/无（行内色点显示）
- ＋添加子任务（行内输入框，回车创建，自动展开）
- 关联主任务（排除自身与子孙防环；时长并入其统计；行内显示「↗已关联」）
- 置顶今日（isPinnedToday）
- 🍅开始专注
- 移动到…（标签清单列表）
- 删除（连带子任务）
- 子任务进度条：主任务行标题下方，颜色=标签色，显示 done/total

**清单树筛选**：全部/今天/标签；分组显示（今天/即将到来/更早/无日期/已完成）

### 3.2 专注（番茄钟）

- **独立页面**：任务胶囊在圆环上方（点击弹任务选择列表，任务池含子任务）；圆环中心 MM:SS，细环 7px 海蓝进度
- **按钮**：放弃 | 开始/暂停（大高亮）| 完成 | 重开
- **顶部切换**：番茄计时/正计时——正计时无时间限制（隐藏分钟选择）；倒计时 15/25/45/60+自定义
- **右侧统计面板**：今日🍅数、今日总分钟、今日专注记录（任务名+分钟+开始时刻）
- **底部浮动计时条**（PomodoroBar）常驻：任意页面可暂停/继续/完成/放弃
- **计时归属铁律**：子任务时长沿 parentTaskId 链并入主任务；任务关联主任务（masterTaskId）后其子树时长一并并入——迁移任务时历史时长跟着走
- **< 30 秒门槛**（M2-V13 实施）：番茄 < 30 秒不计入统计，Toast 提示「专注时间过短，未计入统计」

### 3.3 月历

- **周/月视图切换**：
  - 周视图 = 左侧时间刻度（7:00~23:00 虚线参考）+ 7 列（周一~周日，今天海蓝高亮）+ 列内任务色块条目，总览用不可编辑
  - 月视图 = 7 列×6 行格子，任务色块+白字垂直堆叠（颜色=标签色），今天蓝色圆底
- 显示全部任务（含子任务，带「└」前缀）；无日期任务不显示（底栏提示+顶栏计数徽章）
- 点击日期：当日任务速览+勾选+「+添加当天任务」输入框
- 工具栏：‹›切月/切周、今天、无日期计数

### 3.4 习惯打卡

**周/月/年三视图**：
- **周视图**：顶部星期一~日（今天海蓝+下划线）；每行习惯（icon+名称+🔥连续天数）；打卡格 w-8 h-8 圆形：未打=空心（灰描边）、已打=实心绿#5b8c5a+白✓；hover:scale-110
- **月视图**：表格制——最左列竖排 1~31（今天海蓝）；顶部每习惯一列：icon+横排名（可换行，列宽统一 56~80px）+ 横排两数字：目标 N（橙红#e07a5f，点击行内编辑）/ 打卡 N（茶绿#6a994e）；交叉处打卡格 w-7 h-7 rounded-md
- **年视图**：透明边框表格：习惯名 | 已打卡 | 年目标（默认=月目标×从创建月到 12 月的月数，可点击行内编辑覆盖值，localStorage 存储）

**习惯右键菜单**：编辑名称/更换图标（9 个 emoji+自定义）/设置月目标/删除

### 3.5 数据统计

- 顶部日/月/年切换（海蓝）
- **饼图**：任务专注占比，莫奈/梵高名家色板（10 色循环），日=含子任务明细、月/年=归并主任务
- **年度热力图**（竖排连续填充日历式）：每列 14 格从上到下连续排日期（第 1 列=1 月 1~14 日，第 2 列从 1 月 15 日接续，全年约 27 列）；横轴每 3 个月标记（1 月/4 月/7 月/10 月）；无纵轴无周几；颜色 5 级固定阈值：0/1~30 分/31~60 分/61~120 分/120+ 分（海蓝渐变，1 分钟绝不能深色）；全年满格（未来=最浅色）；hover tooltip「X 月 X 日 · 专注 N 分钟」；图例标注阈值
- **入睡折线图**（仅月视图）：x=日期，y=入睡时间 21:00→05:00 连续；connectNulls=false 断点跳过（M6 由 AI 问询自动录入）

### 3.6 重要日

- **卡片**：图上字下竖版（图 60%）——9 张 PNG 插画（birthday: 热气球/蛋糕/猫咪；festival: 灯笼/烟花/圣诞；custom: 月亮/纸飞机/绿植）
- **文字区**：标题粗体+日期+倒计时胶囊徽章（还有 N 天海蓝/就是今天玫红/已过灰）
- **右键菜单（嵌套）**：编辑（原地表单回填）/ 重复▸（不重复·每年·每月·每周·每天）/ 日期▸（公历·农历）/ 置顶（📌排最前）/ 删除
- **农历**：solarlunar 换算显示「农历 X 月 X 日」，小字「按公历日期提醒」；编辑表单历法切换+实时农历预览
- **已归档折叠区**（可恢复/删除）
- **生理期**（右栏迷你月历）：点干净日期→**居中确认弹窗**「月经开始了吗？[开始][取消]」；已有未结束记录时点其后日期→「月经结束了吗？[结束][取消]」；**绝不自动测算结束**；已记录=浅红#f4a6a6、进行中=深红#e88888（仅开始日单格，不蔓延）、预测=极浅红虚线（平均周期推算，非医疗建议）

### 3.7 AI 聊天 Haruto（M5）

⚠️ 本节为方向性描述。3D 接入技术栈、角色动画驱动方式待 M2.5 验证；角色动画驱动细节待 M7；记忆库架构待 M5。

**设计原则**：人物长什么样（美术资产）和 Haruto 能做什么（AI 能力）是两件事。2D/3D 决策不影响任务系统、记忆库、对话逻辑。

- **微信式**：双方头像气泡（他左你右）、可换头像/聊天背景、拍一拍
- **角色展示**：CharacterStage 组件 + 角色状态文件（美术资产与代码解耦）——**具体格式与驱动方式待 M2.5 定稿**
- **左 1/3 立绘**（表情切换）+ 右 2/3 对话 + 📎发图（视觉识别）
- **人物主页**（点头像）：人设卡/当前情绪/悄悄话日记
- **人设** = persona.md 独立配置
- **消息统一模型**（方向已定）：Haruto 留言/对话统一存 data/ai/chat-messages.json，每条带 sourceType（chat/task/importantDay/period/town）；记忆库唯一提取源
- **记忆库**：M6 设计，**架构待 M2.5 后的专项讨论定稿**
- **M6 定时行为**（需求已登记）：每天 2 次读任务留言 / 每天 09:00 问入睡时间 / 重要日前 7 天+生理期前 3 天自然提起 / 每月 1 日读统计 / 年终总结

### 3.8 书影清单/旅游札记（数据域 M2-V12 已落位；完整 UI = M8-V1）

**书影（AlbumsPage）**：按月相册流——月份倒序分组；跨年折叠；组内卡片网格（图片封面+caption 一行+日期），点击看大图（轻盒：居中放大+左右切换+Esc 关）

**旅游（TravelPage）**：按地点分组 header；组内卡片流（图片+caption+日期）；地点右侧「+」快捷添加

**新建/编辑**（共用 MomentForm modal）：选图（assets:import）+预览、caption、日期选择、分组选择

**右键菜单**：编辑 / 更改分组 / 删除（确认+删除留痕）

### 3.9 小镇（M2.5 技术握手 → M7 正式版）

- **M2.5**：验证 three + @react-three/fiber + glb 接入，产出 CharacterStage + RoomScene + TownPage + 出厂房间资产 + 用户模型读取通路
- **M7 正式版**：陪伴交互 + 空闲日志 + 动作驱动

### 3.10 数据位置（M2-V12 已实现基础能力；M9-V2 完善）

- 默认 `%APPDATA%/MyHaruto/data/`，可通过 config.json 更改；首次启动弹窗选位置（可跳过用默认）
- 设置弹窗「数据位置」区块：当前路径 + 更改位置（复制→校验→重启生效，失败回滚）+ 打开数据文件夹
- 数据版本降级保护：数据版本高于应用支持时提示升级、不强行加载

## 4. 视觉规范

⚠️ 本节描述 **v1.0.0 内部版当前默认配色**。用户多套配色方案正在设计中，**换肤机制为优先规划项**。

### 4.1 当前默认配色
- **日间**：暖白底#fafaf9、深灰字、海蓝#3d7ea6 强调
- **夜间**：主底#1e1e1e、侧栏#121212、L2 底#181818、浅字、彩色圆点保留
- **色板**：海蓝#3d7ea6、成功绿#5b8c5a、警示橙红#e07a5f、茶绿#6a994e、经期红#d94f6e

### 4.2 通用规范
- **图标**：lucide 风格细线 SVG（`src/shared/components/icons.tsx`），UI 层禁用 emoji（习惯 icon 是用户数据除外）
- **微动效**：条目淡入（fadeSlideIn）、打卡 hover:scale、主题渐变 transition、卡片 hover 上浮

### 4.3 换肤机制（优先规划项）
用户可切换多套配色方案（设计师已出多套方案）。
- **技术方向**：CSS 变量 + Tailwind 引用变量（见 TECH.md）
- **约束**：当前代码必须先按"可换肤"设计——硬编码色值一律禁止，全部走变量
- **入口**：设置弹窗「外观」分区（M9-V2 落地）
- **数据**：设置项存 `settings.themeId`
- **归属**：独立立项（M2-V14 池 或 单独立卡），待与规划层细化
